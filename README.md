# Hawk Safety demo assets

Sample images used in demo environments of [Hawk Safety](https://hawksafety.co.uk), a platform for digital food-safety compliance and environmental monitoring.

The `four-seasons/` folder holds illustrative images (kitchen, commissary and purchasing areas) used to give demo accounts a realistic look. They contain demo data only; no real customer data.

These assets are used by the Hawk Safety demo setup and are not a standalone project.
